## 🚀 Featured Project

### 🌍 TravelVerse

TravelVerse is an all-in-one social travel platform that helps travelers document journeys, discover destinations, connect with communities, and plan trips collaboratively.

* ✈️ Travel Logs & Journals
* 🗺️ Interactive Travel Tracking
* 🤖 AI Travel Assistant
* 👥 Travel Communities
* 💬 Real-Time Chat
* 📸 Travel Gallery
* 💰 Expense Splitting
* 🧳 Group Trip Planning
